Agent 与执行沙箱

这一页决定「模型能对代码做什么」。语音误触发是真实存在的——麦克风听到「跑一下」就动手，所以白名单和目录约束默认是收紧的。

已内置的硬性拒绝（改不了，写在代码里）：rm -rf、sudo、mkfs、dd if=、git push --force、curl | sh、重定向与管道串接；文件读写越出仓库根目录也会被拦下。

唤醒词与播报

小爱仍会先自己回答一遍，工作台是抢在它之后覆盖播报。所以唤醒词要足够特别，避免日常聊天被误接管。

语音只播摘要，长内容留在会话记录里。
播报链路：模型回答 → 去掉 Markdown 与代码块（压成「代码略」）→ 按句子边界截到上限 → 注入音箱。 所以回答里的细节不会念出来，想听完整内容就放长字数上限，或者到「会话记录」看原文。
